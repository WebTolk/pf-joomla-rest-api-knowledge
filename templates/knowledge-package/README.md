# Название пакета знаний

Пакет знаний ProcessForge. ID: `<package-id>`. Версия пакета: `<semver>`.
Версии описываемого продукта/данных: `<versions>`.

## Назначение

Предмет, аудитория, задачи и границы применения.

## Состав и чтение

Resource IDs, зависимости и порядок загрузки. Источники, проверенная версия,
происхождение типов/правил и границы проверки. Данные конкретного инстанса,
которые принимающий агент должен получить из его разрешённого профиля.

## Установка

Предлагаемая структура: `<package-root>/<package-id>/` с package.yaml,
README.md, indexes/ и собственными resources/. Окончательное расположение
выбирает установщик по разрешённым корням PF. Указать используемые логические
root IDs, владельцев файлов и действия при конфликте существующего пакета.

## Обновление

Канал, manifest_url/changelog_url из update_sites, ожидаемая структура ZIP,
совместимость, зависимости, место локальных изменений, проверки после применения
и rollback. Записать реальный install_path принимающей стороны локально.

## Лицензия

Лицензия собственных материалов, атрибуция, условия исходного корпуса.
