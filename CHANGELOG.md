# Изменения

## 1.2.0 — 2026-11-14

- Перенесены принятые Joomla Manual PR #724 и связанные PR #1/#2 из ветки автора;
  официальный снимок OpenAPI закреплён по merge commit и SHA-256.
- Исправлены обязательные поля POST статей, тегов, полей/групп, модулей, меню,
  клиентов баннеров, контактов, лент, стилей шаблонов и пользователей/групп.
  Обновлены таблицы, request schemas и примеры в обоих форматах.
- Уточнены явные context/client_id при создании, непустые params и сохранение
  записи даже при ошибочном ответе. Обновлены правила Bearer и token fallback.
- Исправлены пути Media, query path, общий GET файла/каталога и пустой размер
  каталога; 235 OpenAPI-операций покрывают 236 исходных маршрутов.
- Перенесены исправления response schemas и примеры с upstream-происхождением,
  понятные названия операций, теги ресурсов и настраиваемый сервер OpenAPI.
- Добавлена постоянная проверка OpenAPI 3.1, JSON Schema, примеров и регрессий
  обязательных полей; сохранены архивные контракты 5.4.8 и 6.1.3.
- Все 25 пакетов выпускаются согласованным комплектом 1.2.0. Миграция данных
  сайта не требуется; клиентам следует дополнить тела POST. Лицензия JEDL 1.0
  и атрибуция включены для материалов Joomla Manual.

## 1.1.0 — 2026-10-23

- Первый переносимый выпуск 25 PF-пакетов Joomla REST API, 73 ресурса.
- Основной контракт Joomla 6.2.0; 5.4.8 и 6.1.3 сохранены как архивные.
- Обновляемый корпус включён в ZIP владельца joomla.rest-api.documentation.
- Добавлены штатные update_sites и нормализованный манифест сервера PF.
- Пути установки остаются в локальных реестрах принимающего workplace.
- Сохранены схемы, примеры, правила заполнения, HTTP-ошибки, UI fallback
  и доказательства проверки по исходникам.
- Предложена единая структура с README.md, package.yaml, индексом и ресурсами.
