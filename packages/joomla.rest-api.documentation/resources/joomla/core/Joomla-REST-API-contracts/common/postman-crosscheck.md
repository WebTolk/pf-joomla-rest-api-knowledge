# Сверка с коллекцией Postman

Проверен публичный экспорт автора из [j4x-api-collection](https://github.com/alexandreelise/j4x-api-collection), связанный README автора с [указанной документацией Postman](https://documenter.getpostman.com/view/7443864/2s9YywfKez#dae52fb7-d932-4299-8845-90495030df7c). В исходной пользовательской ссылке отсутствовал # перед anchor.

Documenter отдаёт динамическую оболочку; прямое получение его payload не удалось из-за TLS-сертификата. Проверка TLS не отключалась. Побайтовое совпадение авторского экспорта с текущей публикацией Documenter не утверждается. Экспорт — вспомогательный источник примеров; для конкретного выпуска приоритет имеет зарегистрированный исходник Joomla.

Коллекция: Joomla Web Services Collection For Postman; 204 запроса, 76 JSON/raw-тел, 0 сохранённых ответов. Два найденных значения авторизации заменены заглушками. Запросы и скрипты коллекции не исполнялись.

Один параметризованный путь {app} сопоставляется с site и administrator; поэтому число покрытых операций выше числа совпавших запросов. Переменная app в экспорте — шаблон `(site|administrator)`, не выбранный клиент. Проверка тела для обеих ветвей может показать несовпадение client_id и administrator-формы; это не доказательство ошибки site-запроса.

## Несовпадающие маршруты

- GET /v1/v1/languages/content/{language_id}: удвоен v1.
- POST /v1/redirect: в ядре /v1/redirects.
- DELETE /v1/privacy/consents/{consent_id}: этот метод не зарегистрирован.
- 10 запросов /v1/tours и steps: отсутствуют среди webservices-маршрутов всех трёх локальных снимков. Наличие com_guidedtours в админке не создаёт эти REST-маршруты.

В ряде папок контактов/статей/history и полей URL скопирован из другой папки. Сопоставление использует фактический URL и метод, а не подпись папки. В коллекции, в частности, не хватает части contenthistory, contacts/mail, newsfeeds/categories, PATCH config компонента и автообновления. Полные списки — в JSON ниже.

## Уточнения контрактов после сверки

Исправлены выведенные из XML типы скрытых массивов groups/assigned, допустимость числовых строк и наследуемых пустых значений, динамические селекторы без ложного закрытого enum. Добавлены advanced params модулей, раздельные формы site/administrator, формы типов меню, параметры экземпляров custom fields и шаблонов.

Оставшиеся замечания относятся к лишним полям примеров, несовместимым контекстам, client_id выбранной ветви, display_readonly=2 при допустимых 0/1, устаревшим параметрам шаблона и данным, которые действие не читает. additionalProperties=false означает рекомендуемый закрытый профиль формы: Joomla может отбросить лишний ключ, а не обязательно вернуть 400. Успешное сохранение ключа из этого не следует.

В экспорте нет сохранённых ответов. Схемы успешных ответов, HTTP-ошибок и внутренних кодов получены из исходников и локальной проверки форматтеров; Postman не подтверждает их полноту. Все примеры пакетов синтетические, без live API acceptance.
